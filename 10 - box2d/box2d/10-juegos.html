Box2D en juegos

Box2D se usó en juegos como Angry Birds, Limbo, Crayon Physics Deluxe, Tiny Wings, Fantastic Contraption y Happy Wheels (este último, con un port a Flash). En esta página juntamos todo para hacer juegos: cómo se conecta con Phaser, cómo se dibuja suave, y tres mecánicas clásicas armadas con lo que vimos.

Con Phaser

Phaser Box2D trae funciones para atar cuerpos a sprites: SpriteToBox y SpriteToCircle crean un cuerpo del tamaño del sprite, AddSpriteToWorld registra el par, y UpdateWorldSprites copia posición y rotación de cada cuerpo a su sprite. La escala se fija una vez con SetWorldScale(30) (30 píxeles por metro). Esta es la escena del template oficial, comentada:

import * as Phaser from 'phaser';
import { SetWorldScale, CreateWorld, WorldStep, SpriteToBox, AddSpriteToWorld, UpdateWorldSprites,
         CreateBoxPolygon, STATIC, b2DefaultWorldDef, b2DefaultBodyDef, b2Vec2, pxmVec2 } from './PhaserBox2D.js';

class Escena extends Phaser.Scene {
  preload() { this.load.image('logo', 'logo.png'); }
  create() {
    SetWorldScale(30);                                    // 30 px = 1 m
    this.world = CreateWorld({ worldDef: b2DefaultWorldDef() });
    const worldId = this.world.worldId;
    const logo = this.add.image(640, 0, 'logo');
    const caja = SpriteToBox(worldId, logo, { restitution: 0.5, friction: 0.3 });   // cuerpo del tamaño del sprite
    AddSpriteToWorld(worldId, logo, caja);
    // el piso: ojo con el signo de Y (en Box2D crece hacia arriba)
    CreateBoxPolygon({ worldId, type: STATIC, bodyDef: b2DefaultBodyDef(), position: pxmVec2(640, -750), size: new b2Vec2(20, 1) });
  }
  update(time, delta) {
    WorldStep({ worldId: this.world.worldId, deltaTime: delta / 1000 });   // ¡en segundos!
    UpdateWorldSprites(this.world.worldId);               // cuerpo → sprite
  }
}
new Phaser.Game({ type: Phaser.AUTO, width: 1280, height: 768, scene: Escena });
Dos detalles. El template oficial le pasa a WorldStep el delta de Phaser, que está en milisegundos; anda porque termina haciendo un paso por cuadro, pero no recupera cuadros perdidos. Pasale delta / 1000. Y los ayudantes de Phaser convierten Y con el signo cambiado: un sprite en y = 750 píxeles está en y = −25 metros.

Dibujar suave: interpolación

Con paso fijo, la física avanza de a 1/60 s pero la pantalla puede ir a 144 Hz, o la física puede ir a 30 Hz para ahorrar. Si dibujás siempre el último estado, el movimiento sale a saltos. La solución es guardar el estado anterior y el actual de cada cuerpo y dibujar una mezcla, con alfa = acumulado / PASO: lo que sobró en el acumulador dice qué fracción del próximo paso ya pasó.

La misma física dibujada de dos maneras · la física corre a pocos Hz a propósito
¿Qué estoy viendo?
  • Las dos pantallas muestran el mismo mundo. Izquierda: se dibuja el último estado de la física. Derecha: se interpola entre el estado anterior y el actual.
  • Bajá la frecuencia de la física a 10 Hz: la izquierda va a los saltos y la derecha sigue suave (con un paso de retraso, que es el precio).

Un personaje de plataformas

El personaje de física clásico se arma con piezas de toda la unidad:

  • Una cápsula con fixedRotation (capítulos 3 y 4): no se cae ni se traba en los bordes.
  • Fricción 0 en el personaje y control horizontal a mano: la velocidad se acerca a la deseada en cada paso, sin pelear contra el piso ni pegarse a las paredes.
  • ¿Está en el piso? Se recorren sus contactos (b2Body_GetContactData) y se busca uno con la normal apuntando hacia arriba (capítulo 5).
  • Saltar es un impulso; las plataformas que se atraviesan son pre-solve; las monedas son sensores; la plataforma que se mueve es cinemática.
Jugá · ← → o A D para moverte, ↑, W o espacio para saltar (con el mouse arriba del canvas)
¿Qué estoy viendo?
  • El personaje celeste es una cápsula dinámica. Las plataformas celestes se atraviesan desde abajo; la que se mueve es cinemática.
  • Las monedas son sensores: al tocarlas, el evento de sensor las marca y se borran después del paso.
  • Abajo a la izquierda: si el personaje está apoyado (la normal de algún contacto apunta para arriba).
// control: acercar la velocidad horizontal a la deseada, sin tocar la vertical
const v = b2Body_GetLinearVelocity(jugador);
const deseada = direccion * 7;
v.x += (deseada - v.x) * (enElPiso ? 0.25 : 0.08);       // en el aire se controla menos
b2Body_SetLinearVelocity(jugador, v);

// ¿en el piso? algún contacto con la normal hacia arriba
function enElPiso() {
  for (const c of contactos(jugador)) {
    const soyA = b2Body_GetUserData(b2Shape_GetBody(c.shapeIdA)) === 'jugador';
    const ny = soyA ? -c.manifold.normalY : c.manifold.normalY;   // la normal va de A hacia B
    if (c.manifold.pointCount > 0 && ny > 0.6) return true;
  }
  return false;
}
if (saltar && enElPiso()) b2Body_ApplyLinearImpulseToCenter(jugador, new b2Vec2(0, 7 * masa), true);

Una honda

Angry Birds en una demo: el pájaro se tira con un impulso, la trayectoria punteada se calcula repitiendo la misma integración que hace Box2D (Euler semi-implícito con los mismos subpasos), y los cerdos mueren cuando un hit event les llega con suficiente velocidad. La torre es de cajas comunes: la gracia está en los materiales y en el umbral de daño.

Tirá del pájaro hacia atrás y soltá
¿Qué estoy viendo?
  • Arrastrá el pájaro rojo desde la honda. La línea punteada es la predicción: la misma cuenta que va a hacer Box2D, paso por paso.
  • Los cerdos (verdes) mueren si les llega un golpe de más de 4 m/s.
// predecir la trayectoria igual que Box2D: subpasos de Euler semi-implícito
let p = {...inicio}, v = {...velocidadInicial};
const h = (1 / 60) / 4;                                 // paso / subpasos
for (let i = 0; i < 4 * 90; i++) {                      // 90 pasos = 1,5 s
  v.y += gravedad * h;                                  // primero la velocidad…
  p.x += v.x * h; p.y += v.y * h;                       // …después la posición
  if (i % 4 === 3) puntos.push({...p});
}
