Síntesis de sonido

Sintetizar es generar sonido con matemática en vez de grabarlo. Para un juego tiene ventajas enormes: no ocupa espacio, se puede variar infinitamente y puede reaccionar a lo que pasa en el juego en tiempo real. Las consolas de 8 y 16 bits no reproducían grabaciones: tenían chips sintetizadores.

Usá el teclado de abajo (con el mouse o con las teclas A W S E D F T G … y Z/X para cambiar de octava). Toca con el sintetizador de la sección en la que estés.

El punto de partida: osciladores

Un oscilador repite una forma de onda a cierta frecuencia. Las cuatro clásicas suenan muy distinto porque tienen distintos armónicos: frecuencias múltiplo de la fundamental (2f, 3f, 4f…).

  • Seno: solo la fundamental. Puro, suave, como un silbido.
  • Cuadrada: solo armónicos impares (1, 3, 5…) que bajan como 1/n. Hueco, típico de NES y Game Boy.
  • Sierra: todos los armónicos, bajando como 1/n. Brillante, el más rico.
  • Triangular: impares, bajando como 1/n². Suave, como una flauta; el bajo de la NES.

Envolvente ADSR

Un oscilador solo suena "plano", siempre igual. Lo que hace que algo suene a piano, a violín o a disparo es cómo cambia el volumen en el tiempo: la envolvente.

Attack (cuánto tarda en llegar al máximo), Decay (cuánto tarda en bajar), Sustain (nivel mientras mantenés la tecla) y Release (cuánto tarda en apagarse al soltar). Esta envolvente se aplica a todos los sintes de esta página.

Síntesis aditiva

Fourier demostró que cualquier sonido periódico es una suma de senos en frecuencias múltiplo de la fundamental, cada uno con su volumen. La síntesis aditiva hace exactamente eso: elegís cuánto de cada armónico querés y los sumás.

Arrastrá las barras para dibujar el timbre. Fijate que con los armónicos impares en 1/n aparece una cuadrada, y con todos en 1/n, una sierra.

Es muy flexible pero cara: un sonido realista necesita decenas de osciladores que cambian en el tiempo. Los órganos Hammond son aditivos (cada "drawbar" es un armónico).

// la Web Audio API lo hace por nosotros con PeriodicWave:
const real = new Float32Array(N + 1); // cosenos (no los usamos)
const imag = new Float32Array(N + 1); // senos: volumen de cada armónico
imag[1] = 1;     // fundamental
imag[3] = 1/3;   // tercer armónico
imag[5] = 1/5;   // quinto... → onda cuadrada
const onda = ctx.createPeriodicWave(real, imag);
osc.setPeriodicWave(onda);

Modulación de amplitud (AM)

Un oscilador (el modulador) controla el volumen de otro (la portadora). Si el modulador es lento (menos de ~15 Hz) se escucha como un temblor de volumen: un trémolo.

Si el modulador es rápido, ya no se percibe como temblor: aparecen dos frecuencias nuevas a los costados de la portadora, en fc + fm y fc − fm, llamadas bandas laterales. Es lo mismo que el ring modulator, pero conservando la portadora original.

Así funciona la radio AM: la voz modula el volumen de una portadora de cientos de kHz.

const portadora = ctx.createOscillator();  // la nota
const modulador = ctx.createOscillator();  // el que mueve el volumen
modulador.frequency.value = 6;             // 6 Hz = trémolo
const vca = ctx.createGain();
vca.gain.value = 0.5;                      // punto medio
const prof = ctx.createGain();
prof.gain.value = 0.5;                     // cuánto oscila (±0,5)
modulador.connect(prof).connect(vca.gain); // ¡modula la ganancia!
portadora.connect(vca).connect(ctx.destination);

Modulación de frecuencia (FM)

Ahora el modulador controla la frecuencia de la portadora. Lento, es un vibrato. Rápido, aparecen muchas bandas laterales a distancias de fm: en fc ± fm, fc ± 2·fm, fc ± 3·fm…

Dos parámetros lo controlan todo. La relación (ratio) entre modulador y portadora: si es un número entero (1, 2, 3) el sonido es armónico; si no (1,41, 3,5) suena metálico, como una campana. El índice de modulación: cuánto se desvía la frecuencia. Más índice = más bandas laterales = más brillo.

Con dos osciladores salen timbres muy ricos, por eso fue la revolución de los 80: el Yamaha DX7, la placa AdLib / Sound Blaster de los juegos de DOS (chip OPL2) y la Sega Mega Drive (chip YM2612) son sintetizadores FM.

const portadora = ctx.createOscillator();
portadora.frequency.value = 220;
const modulador = ctx.createOscillator();
modulador.frequency.value = 220 * ratio;
const indice = ctx.createGain();
indice.gain.value = I * 220 * ratio;        // desvío en Hz
modulador.connect(indice);
indice.connect(portadora.frequency);         // ¡modula la frecuencia!
portadora.connect(ctx.destination);

Efectos de sonido para juegos, 100 % sintetizados

Herramientas como sfxr / jsfxr generan los sonidos típicos de juegos retro con un oscilador, ruido, una envolvente y barridos de frecuencia. Cada vez que apretás suena un poco distinto.

salida
function moneda(ctx) {
  const t = ctx.currentTime;
  const osc = ctx.createOscillator();
  osc.type = 'square';
  osc.frequency.setValueAtTime(988, t);           // B5
  osc.frequency.setValueAtTime(1319, t + 0.08);   // salta a E6
  const vol = ctx.createGain();
  vol.gain.setValueAtTime(0.3, t);
  vol.gain.exponentialRampToValueAtTime(0.001, t + 0.4);
  osc.connect(vol).connect(ctx.destination);
  osc.start(t);
  osc.stop(t + 0.4);
}
¿Y la síntesis modular? Todo lo de esta página son bloques (osciladores, filtros, envolventes, LFO, amplificadores) conectados entre sí: un oscilador modula la ganancia de otro, un LFO mueve la frecuencia de un filtro. Un sintetizador modular deja esas conexiones a la vista con cables. Es exactamente lo mismo que hacemos con nodo.connect(otroNodo.parametro) en la Web Audio API.
