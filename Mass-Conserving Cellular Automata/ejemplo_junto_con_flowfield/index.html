Modelo Teorico
Presion (exceso): C = max(0, N - N_reposo). Sin hidrostática por altura; cada celda actúa como gas comprimido.
Ley de Fick (Jacobi): J = D · (C_i - C_j) · invDist. Doble buffer ping/pong: lee solo massRead, escribe massWrite, luego swap.
Reposo: Si N < N_reposo la celda no genera outflow (sí puede recibir). Conserva el piso de masa.
Gravedad: Falling sand aparte: abajo → diag abajo → laterales. Rate = cfgGravity. Independiente del flowfield.
Flowfield: V = lerp(V, suma(dir · J_real), alpha). Influencia y lerp con knobs. Snap si |V|² < umbral. Opcional: promedio espacial Moore-8 cada N substeps (blend + frontera agua↔aire).
Chunks: Activo si masa visible o flujo vivo; duerme tras 3 substeps quietos. Procesa activos + anillo 3×3.
