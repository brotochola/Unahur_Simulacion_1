01 Cómo pensar los ejes

Un “mejor” solo es científico si fijás la clase de algoritmo y, si hay micros, el mismo set de checkboxes.

storage + dtype

¿Dónde vive el estado?

Array, TypedArray (u8…u64), filas [][], objeto con clave numérica o "x,y", Map/Set. Dtype solo aplica a typed.

materials / layout

Física y numeración

one vs three. Row / col / Morton → índice o clave. [][] no tiene Morton. obj_xy ignora layout.

pack / bitwise

Encoding vs update

Pack = varias celdas/word. Bitwise = skip/empty sobre el word. u64 usa BigInt (JS & es 32-bit).

micro-opts

Checkboxes, no storage

Borde centinela, double buffer (física distinta al in-place), LUT de vecinos. pad/dbl solo dense.

04 Legalidad

Si no aplica, el control se apaga. Bitwise sin pack es mentira. SoA material[]+variant[] no está: un entero de material alcanza.
