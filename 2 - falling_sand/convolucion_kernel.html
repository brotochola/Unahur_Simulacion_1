📚 Módulo 1: ¿Qué es una convolución de kernel?

Una convolución recorre cada píxel de la imagen y calcula un nuevo valor a partir de ese píxel y sus vecinos, usando una matriz pequeña llamada kernel. Es una operación espacial: cada canal (R, G, B) se procesa por separado, mirando solo posiciones vecinas.

resultado(x,y) = ( Σ imagen(x+i, y+j) · kernel(i,j) ) / factor + offset

El factor normaliza la suma (ej: un kernel de blur que suma 9 se divide por 9 para promediar). El offset se usa en kernels de bordes, para centrar el resultado en gris medio en vez de quedar todo negro. Esta es la misma operación que usan los autómatas celulares (contar vecinos) y las redes neuronales convolucionales.

📚 Módulo 2: ¿Qué es una color matrix?

Una color matrix es una operación por píxel (no mira vecinos): toma los canales R, G, B de ese mismo píxel y calcula nuevos valores de R, G, B como una combinación lineal de los originales. Es el mismo concepto que feColorMatrix en SVG o ColorMatrix en Android, aquí simplificado a una matriz 3x4 (sin canal alfa):

R' = a·R + b·G + c·B + d G' = e·R + f·G + g·B + h B' = i·R + j·G + k·B + l

La cuarta columna es una constante que se suma (offset), útil para brillo o para centrar operaciones como el contraste. Con esta matriz se pueden hacer escala de grises, sepia, invertir colores, aislar un canal, intercambiar canales, saturar/desaturar, etc.

A diferencia del kernel, la color matrix no tiene noción de "tamaño" ni de bordes, porque no mezcla información entre píxeles distintos — solo transforma el color de cada píxel de forma independiente.

🔗 Encadenando ambos módulos

Los dos módulos comparten el mismo resultado de trabajo: cada vez que aplicás una operación (de cualquiera de los dos módulos), esa operación se aplica sobre lo que ya está en el canvas de "Resultado", no sobre la imagen original. Esto te permite armar pipelines como blur → sepia → sharpen → aislar canal rojo en el orden que quieras, o aplicar el mismo kernel varias veces seguidas (ej: aplicar blur 5 veces para un desenfoque más fuerte). Usá "Reiniciar al original" para volver a empezar.
