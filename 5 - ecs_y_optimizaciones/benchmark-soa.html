Benchmark: SoA vs AoS — TypedArrays vs Array vs Objetos

10000 entidades con campos x, y, vx, vy. Cada frame hace x += vx*dt; y += vy*dt y acumula abs(vx)+abs(vy) para que el JIT no elimine el trabajo. Se comparan 7 layouts de memoria distintos.

SoA = 4 arrays separados (x[], y[], vx[], vy[]). AoS objetos = array de {x,y,vx,vy} (un objeto JS por entidad). AoS interleaved = un solo array plano [x,y,vx,vy, x,y,vx,vy, ...] usando TypedArray o Array común. Todos los valores son floats (Math.random()), incluida la variante "Array común" en ambos layouts. Se hace warm-up antes de medir y se reporta la mediana de varias repeticiones.
