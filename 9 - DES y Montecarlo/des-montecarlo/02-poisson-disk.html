Poisson disk sampling

Querés poner 300 árboles en un mapa. Con Math.random() para x e y, algunos quedan encimados y aparecen claros enormes donde no hay nada. El ojo lee eso como "error". Lo que buscamos es azar parejo: puntos al azar, pero con una distancia mínima entre ellos.

Tres formas de repartir puntos

Los tres paneles tienen la misma cantidad de puntos. Cada punto dibuja un disco de radio r/2: si dos discos se tocan, los puntos están a menos de r y quedan marcados en rojo.

  • Uniforme. Cada punto ignora a los demás, así que se forman grumos y huecos. Matemáticamente es un "proceso de Poisson" en el plano: de ahí sale el nombre de la técnica.
  • Grilla con jitter. Una grilla y cada punto movido un poco al azar dentro de su celda. Es barato y parejo, pero si mirás bien se notan las filas y columnas.
  • Poisson disk. Cada punto reserva un disco a su alrededor donde no puede caer otro. Se ve natural y no hay patrones: es lo que en gráficos se llama blue noise.

El algoritmo de Bridson

La versión ingenua (tirar puntos y descartar los que quedan cerca) se vuelve lentísima al final, cuando casi todo tiro cae en zona ocupada. Robert Bridson publicó en 2007 un método que crece desde adentro hacia afuera:

  1. Poné un primer punto al azar y agregalo a la lista de activos.
  2. Elegí un activo al azar y probá hasta k candidatos (típicamente 30) en el anillo entre r y 2r alrededor suyo.
  3. Un candidato sirve si no hay ningún punto a menos de r. Si sirve, se agrega y queda activo.
  4. Si ninguno de los k sirve, ese punto ya está rodeado: sale de la lista de activos.
  5. Repetí hasta que no queden activos.

El truco de velocidad es una grilla de fondo con celdas de lado r/√2. La diagonal de una celda mide r, así que en cada celda entra a lo sumo un punto. Para saber si un candidato está libre, alcanza con mirar las 5×5 celdas vecinas: un costo constante, sin recorrer todos los puntos. Es el mismo spatial hash que usamos para los boids.

Bridson paso a paso · ● activo · ● terminado · + candidato aceptado · × rechazado
function poissonDisk(W, H, r, k = 30, rnd = Math.random) {
  const cell = r / Math.SQRT2, gw = Math.ceil(W / cell), gh = Math.ceil(H / cell);
  const grid = new Int32Array(gw * gh).fill(-1);       // índice del punto en cada celda
  const pts = [], active = [];
  const add = (x, y) => { pts.push([x, y]); active.push(pts.length - 1);
    grid[Math.floor(y / cell) * gw + Math.floor(x / cell)] = pts.length - 1; };
  const libre = (x, y) => {
    const cx = Math.floor(x / cell), cy = Math.floor(y / cell);
    for (let j = Math.max(0, cy - 2); j <= Math.min(gh - 1, cy + 2); j++)
      for (let i = Math.max(0, cx - 2); i <= Math.min(gw - 1, cx + 2); i++) {
        const p = grid[j * gw + i];
        if (p >= 0 && (pts[p][0] - x) ** 2 + (pts[p][1] - y) ** 2 < r * r) return false;
      }
    return true;
  };
  add(rnd() * W, rnd() * H);
  while (active.length) {
    const ai = Math.floor(rnd() * active.length), [px, py] = pts[active[ai]];
    let ok = false;
    for (let t = 0; t < k && !ok; t++) {
      const a = rnd() * 2 * Math.PI, d = r * Math.sqrt(1 + 3 * rnd());   // parejo en el anillo [r, 2r]
      const x = px + d * Math.cos(a), y = py + d * Math.sin(a);
      if (x >= 0 && y >= 0 && x < W && y < H && libre(x, y)) { add(x, y); ok = true; }
    }
    if (!ok) { active[ai] = active[active.length - 1]; active.pop(); }  // sacar sin correr el array
  }
  return pts;
}

Fijate en r * Math.sqrt(1 + 3 * rnd()): es el mismo truco de la raíz del capítulo anterior, para que los candidatos se repartan parejo por el área del anillo y no se amontonen en el borde de adentro.

Densidad variable: un bosque con claros

Si r depende de la posición, la densidad cambia por zonas. Acá r sale de un ruido suave como el de la unidad 1: donde el ruido es bajo, r es chico y el bosque es denso; donde es alto, r es grande y se abren claros. Hay que agrandar la búsqueda en la grilla para cubrir el r más grande.

Bosque procedural · el radio mínimo sigue a un ruido
En juegos Vegetación, rocas y decoración en mapas abiertos: las herramientas de "scatter" de los editores de terreno suelen ofrecer una distancia mínima entre objetos. Puntos de spawn de enemigos o de loot que no queden pegados. Estrellas en un fondo. Semillas para un diagrama de Voronoi: con Poisson disk las regiones salen de tamaño parecido, ideal para biomas, provincias o piedras de un muro. Y en rendering, los patrones de muestreo para sombras suaves usan puntos Poisson disk, porque el ruido que dejan molesta menos que el de una grilla.
