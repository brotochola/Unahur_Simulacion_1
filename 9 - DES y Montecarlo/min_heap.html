Heap vs alternativas: insert, delete, query

Cuatro estructuras compiten en cuatro escenarios de uso: Min-heap (array binario), Array ordenado (insert con búsqueda binaria), Array sin ordenar (push simple, todo lo demás es scan lineal) y Resort ingenuo (llamar sort() cada vez que hace falta el mínimo). Mismo set de operaciones para las cuatro — comparación justa.

Configuración

⚠ Con tamaños/operaciones grandes, "array sin ordenar" y "resort ingenuo" son O(n) y O(n log n) por operación — puede tardar varios segundos. Desmarcalas si querés resultados rápidos.
Cómo leer esto: "Build+Drain" muestra el caso de libro de texto (heapsort). "Cola de prioridad" es el caso real más común — algo va insertando y extrayendo el mínimo constantemente (schedulers, Dijkstra). "Read-heavy" aísla el beneficio de peek en O(1): insertás una vez y consultás mil veces. "Mix aleatorio" simula un sistema real donde no sabés qué operación viene. El chequeo de correctitud compara la secuencia de mínimos devueltos por cada estructura contra el array sin ordenar (ground truth por fuerza bruta) — si alguna estructura tiene un bug de implementación, se ve acá.
